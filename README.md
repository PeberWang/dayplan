# DayPlan

A small paper card that sits on your Mac desktop and shows what you planned for today.

It is not a calendar and not a task manager. It is the one piece of paper you keep looking at. Four things, tick them off, edit them in place when the day changes.

- A fixed 360 × 620 borderless card in the corner. No title bar, no traffic lights, no resize handle.
- Other windows cover it. It never floats above your work.
- Click a row to tick it. Double-click any text to edit. Add or delete rows without leaving the card.
- One button shows the last seven days. `Cmd+3` opens a stats window with a 30-day chart and a short note.
- Chinese and English, following the system language.

## Install

Requires macOS 14 or later and the Xcode Command Line Tools (`xcode-select --install`).

```sh
git clone https://github.com/PeberWang/dayplan.git
cd dayplan
./scripts/install.sh
```

The script builds the app and copies it to `~/Applications/DayPlan.app`.

## Data

By default plans live in:

```
~/Library/Application Support/DayPlan/plans/YYYY-MM-DD.json
```

Override with the `DAYPLAN_DIR` environment variable or a `dataDir` user default:

```sh
launchctl setenv DAYPLAN_DIR /path/to/plans
# or
defaults write io.github.peberwang.dayplan dataDir /path/to/plans
```

One file per day. The app reads the file for today, watches it, and writes back on every edit. Anything else that can write a JSON file can drive it: a shell script, a cron job, an agent.

```json
{
  "date": "2026-11-24",
  "weekday": "Tue",
  "title": "Analysis chapter",
  "subtitle": "14 units",
  "blocks": [
    {
      "id": "a1b2c3d4",
      "origin": "ai",
      "time": "11:00 – 12:00",
      "units": 2,
      "text": "Reread the backward solution",
      "note": "Mark doubts, do not rewrite",
      "done": false
    }
  ],
  "footer": "Finish the model today.",
  "updated_at": "2026-11-24T17:14:00Z"
}
```

`id` is stable and is what edits and deletes match on. `origin` is `ai` for rows written by whatever generated the plan and `user` for rows added in the card. Unknown fields are preserved on write.

Before each write the previous file is kept as `<date>.prev.json`.

## Build

```sh
swiftc -O -parse-as-library -o DayPlan DayPlanApp.swift
```

A note for anyone extending this: the Xcode Command Line Tools ship a SwiftUI without the macro plugin, so `@State`, `@Binding` and `@Observable` do not compile. The app uses `ObservableObject` and `@StateObject` for that reason.

The icon is generated by `make-icon.swift`:

```sh
swiftc -O -o makeicon make-icon.swift && ./makeicon assets/icon-1024.png
```
